# Web Preview (Non-App Files)

This directory contains files that were used to generate a web-based preview of the app UI during development. **These files are NOT part of the iOS app bundle and do not affect the App Store submission.**

- `preview.html` — Static HTML/CSS/JS marketing preview page
- `Dockerfile` — Docker container configuration for serving the preview via nginx
- `nginx.conf.template` — nginx configuration template

These files exist solely for internal development/design iteration and have no relation to the native SwiftUI iOS app source code in `TrueCostAuto/`.
